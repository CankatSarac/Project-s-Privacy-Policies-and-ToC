## Description

Emoji Lane Run turns memory practice into a fast, colorful lane-running game.

Memorize the emoji sequence, then run through the lanes and make the right choices before your memory fades. Every session is built around your own progress, with clear feedback that keeps practice encouraging and replayable.

Highlights:

- Memorize emoji lanes and react under pressure
- Track your best span, gates cleared, runs, and streaks
- Use sound and haptic cues as optional memory prompts
- Create separate local profiles for people sharing one device
- Review your own trends with simple progress reports
- Export a run card or family report through Apple's share sheet
- Play offline with your gameplay data stored on your device
- Optional Game Center leaderboards and achievements
- Optional Runner's Mind Plus upgrades through Apple

Emoji Lane Run is a practice game, not a medical, psychological, or cognitive
diagnosis. Results reflect your in-game sessions and normal day-to-day
variation.

No account is required. No advertising or third-party analytics SDK is used in
the current version.
